  <action>
    创建 `deploy/optimize/check_env.ps1`，实现标准 PowerShell 诊断脚本：
    1. **参数与权限设计**：
       - 支持 `[switch]$Fix` 参数与 `[switch]$Help` 参数。
       - **默认行为（无参数）**：纯只读检查，严禁触发任何 UAC 提权弹窗，普通权限即可秒级跑完。
       - **修复模式 (`-Fix`)**：检测当前是否具有管理员权限（`[Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent().IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)`）。若无管理员权限，则通过 `Start-Process pwsh (或 powershell) -Verb RunAs -ArgumentList "-NoProfile -File $PSCommandPath -Fix"` 弹出 UAC 提权执行并退出当前进程。
    2. **四大检测核心模块**：
       - `Check-GpuTopology`:
         - 通过 `Get-CimInstance Win32_VideoController` 枚举显示适配器名称、显存容量与驱动版本；
         - 查询注册表 `HKCU:\Software\Microsoft\DirectX\UserGpuPreferences`；
         - 校验 `MuMuPlayer.exe` 是否包含 `GpuPreference=2;`（独显高性能）；
         - 校验 `thorium.exe` 与 `AzurLaneAutoScript.exe` 是否包含 `GpuPreference=1;`（核显节能）。
       - `Check-TdrDelay`:
         - 查询 `HKLM:\SYSTEM\CurrentControlSet\Control\GraphicsDrivers` 下的 `TdrDelay`、`TdrDdiDelay` 与 `TdrLevel`；
         - 判定 `TdrDelay` 是否存在且 >= 8。若未设置或为默认 2s，输出标黄 `[WARN]`；若 >= 8 且 TdrLevel == 3，输出标绿 `[PASS]`。
       - `Check-MuMuConfig`:
         - **四重级联查找 MuMu 路径**：
           1. 运行中进程：`Get-Process MuMuPlayer, MuMuNxDevice -ErrorAction SilentlyContinue | Select-Object -ExpandProperty Path -First 1`；
           2. 卸载注册表：`HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\MuMuPlayer-12.0` 的 `InstallLocation`；
           3. MuiCache 记录；
           4. 常见默认路径（`C:\Program Files\Netease\MuMuPlayer-12.0\`, `D:\Program Files\Netease\MuMuPlayer-12.0\`, `E:\Program Files\Netease\MuMuPlayer-12.0\` 等）。
         - **NemuIPC DLL 探测**：检查是否存在 `external_renderer_ipc.dll`（探测 `<MuMuPath>\shell\sdk\`, `<MuMuPath>\nx_device\12.0\shell\sdk\`, `<MuMuPath>\nx_main\sdk\`）。
         - **保活配置校验**：扫描 `<MuMuPath>\vms\MuMuPlayer-12.0-*\configs\customer_config.json`，解析 JSON 判断 `customer.app_keptlive`。若为 `true`，输出标红 `[FAIL] (保活已开启，严重破坏 NemuIPC)`。
       - `Check-PageFileAndMemory`:
         - 提取物理与虚拟内存：`Get-CimInstance Win32_OperatingSystem` 提取总/空闲物理内存与虚拟内存；
         - 分页文件探测：`Get-CimInstance Win32_PageFileUsage` 提取分页文件所在盘符；
         - 磁盘类型判定：通过 `Get-PhysicalDisk` 或驱动器类型判断 PageFile 是否落在 SSD 固态盘上。若发现机械盘 (HDD) 存在分页文件，输出标红 `[FAIL]`。
    3. **格式化看板与自愈操作 (`-Fix`)**：
       - 在控制台打印带颜色高亮的格式化看板（`[PASS]`, `[WARN]`, `[FAIL]`），底部输出总结与调优指南链接（`doc/low_spec_tuning_guide.md`）。
       - 当指定 `-Fix` 且具备提权后：
         - 写入 `HKLM:\SYSTEM\CurrentControlSet\Control\GraphicsDrivers`：`TdrDelay=8`、`TdrDdiDelay=8`、`TdrLevel=3`。
         - 若探测到 MuMuPlayer、Thorium、Alas 路径，向 `HKCU:\Software\Microsoft\DirectX\UserGpuPreferences` 自动写入对应的 `GpuPreference` 项。
         - 打印修复完成提示，提醒用户重启电脑使 TDR 驱动级生效。
  </action>
