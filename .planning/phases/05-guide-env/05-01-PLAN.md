# Plan 05-01: 核心调优指南文档与 TDR 容灾注册表配置

<objective>
为老旧双核移动平台（i5-4210H + GTX 960M / HD 4600）在 7×24h 挂机并发场景下提供完整的系统级调优指南主文档，并配套生成 Windows TDR 容灾加固与恢复注册表配置文件，彻底解决双显卡竞逐、MuMu 12 保活破坏 NemuIPC、虚拟内存 PageFile 磁盘颠簸以及 LiveKernelEvent 141 驱动重置问题。
</objective>

<tasks>
<task id="05-01-01" type="config">
  <name>创建 TDR 注册表加固与默认恢复配置文件</name>
  <read_first>
    - .planning/phases/05-guide-env/05-CONTEXT.md
    - .planning/phases/05-guide-env/05-RESEARCH.md
  </read_first>
  <action>
    1. 确保目录 `deploy/optimize/` 存在。
    2. 创建 `deploy/optimize/enable_tdr_delay_8s.reg`：
       - 使用标准标头 `Windows Registry Editor Version 5.00`。
       - 目标键路径：`[HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\GraphicsDrivers]`。
       - 写入 `"TdrDelay"=dword:00000008`（GPU 调度引擎超时由 2s 放宽至 8s）。
       - 写入 `"TdrDdiDelay"=dword:00000008`（DDI 驱动接口超时由 2s 放宽至 8s）。
       - 写入 `"TdrLevel"=dword:00000003`（恢复级别保持为 3: TdrLevelRecover，超时尝试重置恢复，严禁设为 0 关闭）。
    3. 创建 `deploy/optimize/restore_tdr_delay_default.reg`：
       - 使用相同标头与键路径。
       - 写入 `"TdrDelay"=-`（减号表示删除自定义键值，恢复 Windows 默认行为）。
       - 写入 `"TdrDdiDelay"=-`。
       - 写入 `"TdrLevel"=dword:00000003`。
  </action>
  <acceptance_criteria>
    - 文件 `deploy/optimize/enable_tdr_delay_8s.reg` 存在，包含 `[HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\GraphicsDrivers]`、`"TdrDelay"=dword:00000008`、`"TdrDdiDelay"=dword:00000008`、`"TdrLevel"=dword:00000003`。
    - 文件 `deploy/optimize/restore_tdr_delay_default.reg` 存在，包含 `"TdrDelay"=-`、`"TdrDdiDelay"=-`、`"TdrLevel"=dword:00000003`。
    - 两个文件均以 UTF-8 编码且不含损坏 BOM。
  </acceptance_criteria>
  <verify>
    <command>pwsh -NoProfile -Command "Get-Content deploy/optimize/enable_tdr_delay_8s.reg; Get-Content deploy/optimize/restore_tdr_delay_default.reg"</command>
  </verify>
</task>

<task id="05-01-02" type="doc">
  <name>编写弱机与模拟器协同调优指南主文档</name>
  <read_first>

  <action>
    创建 `doc/low_spec_tuning_guide.md`，按照「分层速查手册 + 故障排查手册 (FAQ)」结构编写，全文必须包含以下核心章节：
    1. **前言与硬件基准画像**：说明针对 i5-4210H (2C4T) + GTX 960M 2GB + HD 4600 + 16GB 内存（15.8GB 虚拟内存置换压力）并发 Thorium 高清直播与 Alas 7×24h 挂机的三大痛点（显存击穿 TDR 141、SSD 磁盘换页颠簸、CPU 双核算力竞逐）。
    2. **3 分钟极速配置推荐表**：
       - GPU 分流：MuMu 12 绑定独显（高性能=2），Thorium 与 Alas 绑定核显（节能=1）。
       - MuMu 12：2 核 CPU，3072 MB 内存，DirectX 11 模式，30 FPS，后台挂机保活彻底关闭。
       - 虚拟内存：仅限高速 SSD，固定初始 16384 MB / 最大 20480 MB，关闭 HDD 分页。
       - TDR 延迟：8 秒超时缓冲（导入 `deploy/optimize/enable_tdr_delay_8s.reg`）。
       - 系统电源：平衡模式，最大处理器状态 99% 关闭过热睿频，关闭 USB 选择性暂停。
    3. **分步配置操作详解**：
       - **Windows 图形首选项硬分流**：详细步骤指导 Win10/Win11 进入“设置 -> 系统 -> 显示 -> 图形设置/显示卡”，添加 `MuMuPlayer.exe`（独显高性能）、`thorium.exe`（核显节能）、`AzurLaneAutoScript.exe`（核显节能）。解析注册表 `HKCU\Software\Microsoft\DirectX\UserGpuPreferences` 的键值数据规范（`GpuPreference=2;` 与 `GpuPreference=1;`）。提供 Nvidia 控制面板（`nvcplui.exe`）全局设为“自动选择/集成图形”的防范说明。
       - **MuMu 12 性能参数与保活关闭**：解释为何只能分配 2 核（留出 2 线程给 Python 图像识别与 QuickSync 视频硬解），解释 30 FPS 降低 40% 发热，重点深度剖析为何必须在设置中心关闭“后台挂机保活”（`customer_config.json` 中 `"customer.app_keptlive": false`，保活会劫持 SwapChain 渲染表面导致 NemuIPC 抛出 RPC 1722/1726 异常并退化为高 CPU ADB 截图）。
       - **SSD PageFile 虚拟内存规整**：详细指导在“系统属性 -> 性能选项 -> 虚拟内存”中，将机械硬盘 HDD 分页全部关闭，仅在固态硬盘 SSD 设置固定尺寸（16384MB ~ 20480MB），解释固定尺寸如何彻底杜绝 Windows 动态分配造成的 100% 磁盘假死。
       - **TDR 注册表加固与防蓝屏**：解释 WDDM 默认 2s 超时机理与导入 `enable_tdr_delay_8s.reg` 的安全收益，附上 `restore_tdr_delay_default.reg` 还原说明。
    4. **运行状态验证与常见故障排查 (FAQ)**：
       - 提供任务管理器 GPU 0 / GPU 1 与 GPU-Z 的双显卡分工对照指标（GPU 1 独占 MuMu 3D 引擎，GPU 0 承担 Thorium Video Decode 与桌面合成）。
       - NemuIPC 掉落 ADB 告警排查四步法。
       - LiveKernelEvent 141 黑屏排查与散热清灰建议。
  </action>
